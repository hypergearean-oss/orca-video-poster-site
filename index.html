Orca Video Poster

Orca Video Poster is a small desktop tool that uploads videos to YouTube channels that you own. It runs on your own Windows computer. Every upload is private by default, and public publishing is off unless you turn it on.

What it does

  • Connects a channel with Google sign-in. You choose which Google account and YouTube channel to use. The tool checks that the signed-in channel matches the channel ID you set, and saves nothing if it does not.
  • Uploads private videos. Each upload is sent as private, then the tool reads it back to confirm the privacy setting, the channel and the processing status.
  • Keeps channels separate. Each channel has its own saved sign-in, channel pin, upload history and duplicate check, so one channel's credentials are never used for another.
  • Prevents duplicates. A file that was already uploaded to the same channel is not uploaded again.
  • Keeps you in control. Public publishing is disabled by default and needs an explicit owner approval.

How it uses Google

The tool uses Google's YouTube Data API through an OAuth client that you create and control in your own Google Cloud project. It requests access to your YouTube account so it can read your channel details, upload videos and check their status. It does not run on a server operated by us, and it does not send your data anywhere except to Google and YouTube.
